🌀 About The Project

SAT0RU is an interactive cursed technique visualizer inspired by the hit anime series Jujutsu Kaisen (呪術廻戦). Using advanced hand tracking technology, this project lets you become a sorcerer and perform iconic techniques from the series with simple hand gestures.

The application combines Mediapipe's real-time hand tracking with Three.js particle systems to create stunning, volume-based visual effects that respond to your movements. Every gesture triggers a unique cursed technique visualization, making you feel like you've entered the world of Jujutsu Kaisen.

🔮 Detailed Techniques

💜 Secret Technique: Hollow Purple

"A chaotic singularity combining attraction and repulsion"

When you bring your thumb and index finger together in a pinching motion, you unleash the legendary Hollow Purple. The visualization creates a mesmerizing particle vortex that both pulls in and pushes away surrounding particles, mimicking the destructive nature of this forbidden technique.

🌌 Domain Expansion: Infinite Void

"A multi-layered celestial domain"

Cross your index and middle fingers to activate Gojo Satoru's signature Domain Expansion. Watch as an intricate cosmos unfolds before you, featuring:

· A brilliant event horizon ring
· Vertical streams of infinite information
· A deep, rotating celestial background
· Star-like particles representing the void's endless knowledge

🔴 Cursed Technique Reversal: Red

"A blinding white-hot core of repulsive force"

Point your index finger upward to channel the reversal of Cursed Technique. The visualization generates a violent, jagged sphere of pure repulsive energy, radiating outward with intense particle effects that mimic the technique's destructive potential.

⚫ Domain Expansion: Malevolent Shrine

"The King of Curses awakens"

Extend your hand flat or form a prayer gesture to summon Sukuna's Domain. Dark, ominous particles swirl around you, creating an aura of pure malevolence that pays homage to the most feared curse in history.

🚀 Getting Started

Prerequisites

· A modern web browser (Chrome, Edge, Firefox recommended)
· A working webcam
· JavaScript enabled

Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Dbz-Mahin7x/Cursed-Energy.git
   cd Cursed-Energy
   ```
2. Run the project
   Option A: VS Code with Live Server (Recommended)
   · Install the "Live Server" extension
   · Right-click index.html
   · Select "Open with Live Server"
   Option B: Direct Browser
   · Simply double-click index.html to open in your browser
   · Note: Some browsers may have CORS restrictions
3. Allow Camera Access
   · When prompted, allow the website to access your camera
   · Position yourself in good lighting
   · Make sure your hands are clearly visible

---

🎮 How to Use

1. Stand back so your upper body is visible to the camera
2. Ensure good lighting for accurate hand tracking
3. Try different gestures to trigger techniques:
   · 🤏 Pinch – Hollow Purple
   · ✝️ Cross fingers – Infinite Void
   · ☝️ Point up – Cursed Reversal: Red
   · ✋ Flat hand – Malevolent Shrine
4. Watch the magic happen as particles respond to your movements
