🌀 About The Project
SAT0RU is an interactive cursed technique visualizer inspired by Jujutsu Kaisen. Using advanced hand-tracking technology, this project transforms your webcam into a sorcerer's tool, allowing you to perform iconic techniques through real-time hand gestures.
By combining Mediapipe's skeletal tracking with Three.js particle systems, the application creates volume-based visual effects that respond dynamically to your movements.
⚡ Cursed Techniques
| Technique | Gesture | Visual Effect |
|---|---|---|
| 💜 Hollow Purple | 🤏 Pinch (Thumb + Index) | Chaotic singularity with attraction & repulsion. |
| 🌌 Infinite Void | 🤞 Cross (Index + Middle) | Multi-layered celestial domain with event horizon. |
| 🔴 Reversal: Red | ☝️ Index Pointing Up | Blinding white-hot repulsive sphere. |
| ⚫ Malevolent Shrine | ✋ Flat Hand / Prayer | Dark, ominous King of Curses aura. |
🔮 Technique Deep-Dive
💜 Secret Technique: Hollow Purple
"A chaotic singularity combining attraction and repulsion."
When you pinch your fingers, a mesmerizing particle vortex is unleashed, mimicking the destructive nature of the forbidden technique.
🌌 Domain Expansion: Infinite Void
"A multi-layered celestial domain."
Crossing your fingers unfolds an intricate cosmos featuring:
 * A brilliant event horizon ring.
 * Vertical streams of infinite information.
 * A deep, rotating celestial background.
🛠️ Built With
 * Mediapipe – Real-time skeletal hand tracking.
 * Three.js – 3D particle systems and GPU-accelerated visuals.
 * Google Gemini 3 – AI-powered logic optimization and boilerplate generation.
 * HTML5/CSS3/JS – Modern web stack for seamless browser performance.
🚀 Getting Started
1. Installation
# Clone the repository
git clone https://github.com/Dbz-Mahin7x/Cursed-Energy.git
cd Cursed-Energy

2. Run the Project
 * Option A (Recommended): Use the Live Server extension in VS Code. Right-click index.html and select "Open with Live Server."
 * Option B: Simply double-click index.html. (Note: Some browsers may block webcam access on local file paths due to security settings).
3. Setup
 * Allow Camera Access when prompted.
 * Ensure you are in a well-lit environment for the best tracking accuracy.
